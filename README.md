# Island: Dynamic Island для Windows

Чёрная «пилюля» сверху экрана, как на iPhone. Показывает время, погоду и музыку, а если навести курсор, раскрывается в панель с плеером, буфером обмена, заметками, погодой и быстрыми действиями. Бесплатно и с открытым кодом.

## Как запустить

### Вариант 1: готовый .exe (проще всего)
1. Открой **[Releases](https://github.com/kiyoushii/dinamic-island_win11/releases/latest)** (справа на главной странице репозитория).
2. Скачай `Island-portable-*.exe` (запускается без установки) или `Island-Setup-*.exe` (установщик).

> Windows SmartScreen может предупредить «неизвестный издатель», потому что exe не подписан. Нажми «Подробнее → Выполнить в любом случае».

### Вариант 2: из исходников
1. Поставь [Node.js](https://nodejs.org) (LTS).
2. Скачай репозиторий (Code → Download ZIP) и распакуй, например, в `C:\Island`.
3. Дважды кликни `start.bat`. Первый запуск установит зависимости, это займёт минуту-две.

Собрать свой exe: `npm install`, затем `npm run dist`. Файлы появятся в папке `dist`.

## Что умеет

| | |
|---|---|
| **Пилюля** | Время, погода, обложка трека и эквалайзер, котик, который следит за курсором. Пока играет музыка, снизу «дышит» волна в цвет обложки |
| **Музыка** | Работает с любым плеером, который показывает себя в системной панели громкости Windows: Spotify, Яндекс Музыка, браузер, медиаплеер. Есть пауза, перемотка, громкость и **синхронные слова песен** (LRCLIB) |
| **Наведи курсор** | Остров раскрывается: плеер, громкость, быстрые действия и закреплённые программы |
| **Буфер** | Запоминает всё, что ты копируешь. Поиск по паре букв, закрепление. Клик по записи вставляет её туда, где ты печатал |
| **Полка** | Перетащи файл на остров, он подождёт. Потом перетащи его с полки куда нужно |
| **Загрузки** | Пока что-то скачивается в «Загрузки», в пилюле видно имя файла и скорость |
| **Alt+Space** | Одна строка на всё: программы и файлы, калькулятор (`12*34,5`), единицы (`10 миль в км`), валюты (`100 долларов в рублях`), таймер (`таймер 5 мин`), напоминания (`напомни позвонить маме завтра в 9`), команды (`> ipconfig`), поиск в браузере и вопрос ИИ |
| **Скриншоты** | Область, весь экран, пипетка, чтение QR-кода с экрана. Результат сразу в буфере и в папке «Изображения\Island» |
| **Текст** | Раскладка (ghbdtn → привет), транслит, регистр, убрать переносы и лишние пробелы, JSON, Base64, URL, «чистый текст» |
| **Чат с ИИ** | Можно приложить файл и спросить. Бесплатно через Ollama (локально) или ключ Groq / OpenRouter |
| **Заметки** | Папки, чек-листы, выделение, таймер с кольцом (5/10/15/25/45 мин), напоминания обычной фразой |
| **Погода** | Сейчас, по часам и на неделю, плюс предупреждение «через 20 минут дождь». Данные Open-Meteo, без ключей |
| **Агенты в терминале** | Claude Code сообщает острову, что работает (пульсирующая точка, котик задумывается), ждёт твоего решения или закончил (с итогом ответа). Подключается одной кнопкой в настройках |
| **Запись экрана** | 60 кадров в секунду, MP4 (H.264) со звуком системы. Сам остров в запись не попадает. Таймер и кнопка «Стоп» прямо в пилюле. Файлы в «Видео\Island» |
| **VPN** | Переключатель для Happ / AmneziaVPN (запуск и закрытие приложения) или для туннеля AmneziaWG по .conf. Остров сам видит, включён ли VPN |
| **Bluetooth** | Сопряжённые устройства: подключено или нет, заряд батареи. Можно включить или выключить Bluetooth |
| **Управление** | Блокировка, сон, перезагрузка, выключение, тёмная тема Windows, «Не беспокоить» |

## Настройка ИИ (бесплатно)
* **Ollama** работает на твоём компьютере без интернета. Установи с [ollama.com](https://ollama.com) и выполни `ollama pull llama3.2`. В настройках острова ничего менять не нужно.
* **Groq**: возьми бесплатный ключ на console.groq.com. Адрес `https://api.groq.com/openai/v1`, модель `llama-3.3-70b-versatile`.
* **OpenRouter**: адрес `https://openrouter.ai/api/v1`, подойдут модели с пометкой `:free`.

## Агенты: как подключить
Настройки острова (шестерёнка) → «Агенты» → **Подключить**. Работает и в терминальном Claude Code, и в Claude Desktop. Остров добавит http-хуки в `~/.claude/settings.json` (рядом сохранится копия `settings.json.island-backup`), потом начни новый чат. Другие агенты и свои скрипты тоже могут слать события:
```
curl -X POST http://127.0.0.1:47821/agent/codex -d "{\"event\":\"done\",\"text\":\"Сборка готова\"}"
```
События: `start` (работает), `ask` (ждёт ответа), `done` (закончил), `end` (убрать).

## VPN: как настроить
* **Happ / AmneziaVPN.** Остров находит программу сам (или укажи её в настройках). Включение запускает приложение, выключение закрывает его и сбрасывает системный прокси. Чтобы VPN включался сразу, включи в самом приложении «подключаться при запуске».
* **AmneziaWG по конфигу.** Укажи в настройках файл `.conf` (его можно выгрузить из AmneziaVPN, раздел «Поделиться» → формат AmneziaWG) и поставь [AmneziaWG](https://github.com/amnezia-vpn/amneziawg-windows-client/releases). Остров будет поднимать туннель сам, без приложения. Windows спросит права администратора.

## Чего пока нет
* Распознавание текста с экрана (OCR)
* Перехват системных уведомлений Windows (Telegram и т.п.): Windows даёт доступ к ним только приложениям из Microsoft Store
* Подключение и отключение конкретного Bluetooth-устройства в один клик: у Windows для этого нет открытого способа, поэтому кнопка открывает параметры Bluetooth

## Как устроено
* `src/main.js`: окно поверх всех, сквозные клики мимо острова, буфер, загрузки, скриншоты, поиск программ, напоминания
* `src/features.js`: агенты (локальный сервер на 127.0.0.1:47821), VPN, запись экрана, Bluetooth
* `src/win/media.ps1`: мост к Windows через PowerShell (музыка через SMTC, громкость через Core Audio)
* `src/win/bt.ps1`: Bluetooth-устройства и радио
* `src/renderer/`: интерфейс острова: `app.js` (логика), `tools.js` (текст, калькулятор, разбор фраз), `style.css`

Все данные (буфер, заметки, настройки) лежат только у тебя в `%APPDATA%\Island\island.json`.
